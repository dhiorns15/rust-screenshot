# Security

Please report security problems privately, not in a public issue: use
[Report a vulnerability](https://github.com/dhiorns15/rust-screenshot/security/advisories/new) on the
repository's Security tab. Say what you found, how to make it happen, and which version and OS you're
on. You'll hear back within a week, and we'll agree on when it's made public once it's fixed.

Worth reporting, for example:

- Passwords, keys or webhook addresses for *Push to* ending up anywhere other than Windows'
  Credential Manager or the desktop's keyring: settings, logs, crash reports, System info, or sent to
  a server they don't belong to.
- The updater installing something that isn't an RSnip release from this repository.
- Screenshots, recordings or their text being sent anywhere you didn't choose.
- A crafted file in the save folder that makes RSnip run code or write outside that folder.

Fixes go into the latest release, which RSnip offers as an update.
