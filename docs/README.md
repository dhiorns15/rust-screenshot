# RSnip documentation

The details behind [the README](../README.md), a page for each part of RSnip.

- [Installing on Windows](windows.md): the installer, or `rsnip.exe` on its own.
- [Capturing](capturing.md): every way to take a screenshot or record the screen, and the shortcuts.
- [The editor, library and Gallery](editor.md): the annotation tools, saving and exporting, the
  library and its search, the Gallery page, and playing and trimming recordings.
- [Places to push to](destinations.md): sending screenshots and recordings to SFTP, WebDAV, S3, SMB
  shares, FTPS, Dropbox, Discord, Slack, Immich, PhotoPrism or any upload API, and how to set up each.
- [Settings](settings.md): what each section of the Settings window does, where settings are kept,
  release candidates and crash reports.
- [Command line](command-line.md): the `rsnip` options on Windows and on Linux.
- [RSnip on Linux](linux.md): what works there, installing it, screenshots and recording, and what
  each needs.
- [Troubleshooting](troubleshooting.md): when something doesn't work as it should.
- [Building](building.md): building RSnip from source, running the tests and publishing a release.

To change RSnip, see [CONTRIBUTING.md](../CONTRIBUTING.md).
